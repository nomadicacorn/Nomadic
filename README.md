# ÓRBITA — 빛과 소리의 우주 오퍼레이터

카메라, 마이크, 손끝, 폰의 기울기에 반응하는 **모바일 우주 인터랙티브 웹 작품**입니다.
TouchDesigner의 오퍼레이터 파이프라인(TOP / CHOP / SOP / feedback)을 WebGL2 셰이더로 브라우저 안에 옮겨 왔습니다.
설치가 필요 없고 폰에서 링크로 바로 열 수 있습니다.

## 실행

```bash
python3 -m http.server 8000   # 또는 아무 정적 서버
```

- 카메라와 마이크는 **HTTPS**(또는 localhost)에서만 동작합니다. GitHub Pages에 올리면 폰에서 바로 열 수 있습니다
  (Settings → Pages → Branch 선택).
- 데스크톱에서는 마우스가 시점, `1`–`4`는 모드 전환, `Space`는 초신성, `H`는 오퍼레이터 HUD를 켜고 끕니다.

## 터치디자이너에서 가져온 것

| TouchDesigner | ÓRBITA |
|---|---|
| `videodevin TOP → monochrome → cache → subtract` | 카메라 → 휘도 / **프레임 차분 모션** / 소벨 **엣지** (`CAM_FS`) |
| `audiodevin CHOP → audiospectrum → analyze` | 저·중·고음 밴드, 자동 게인, **비트 검출**, 256-bin 스펙트럼 텍스처 |
| `CHOP to TOP` | 스펙트럼을 텍스처로 올려 파티클이 직접 읽음 |
| GPU 파티클 SOP / instancing | 65k–147k 파티클, MRT 핑퐁 시뮬레이션 |
| `feedback TOP + transform + displace` | 줌·회전·노이즈 변위·색상 회전이 있는 피드백 루프 |
| `blur / bloom / composite` | 블룸 체인, 색수차, 그레인, 톤매핑 |
| 노드 네트워크 화면 | 실시간 미터가 달린 오퍼레이터 HUD (`⌗` 버튼) |

## 네 가지 우주 (모드)

1. **성운 NEBULA** — 발산 없는 흐름장 위의 별가루. 저음이 성운을 부풀리고 몸의 움직임이 별을 흩뿌립니다.
2. **성좌 거울 MIRROR** — 카메라 밝기를 깊이로 쓰는 포인트 클라우드. 폰을 기울이면 내 얼굴의 별 조각을 옆에서 볼 수 있습니다.
3. **궤도 ORBIT** — 중심 중력과 회전 원반. 손가락이 블랙홀이 됩니다.
4. **펄서 PULSAR** — 스펙트럼 대역마다 하나의 구 껍질이 대응하여, 목소리의 주파수가 행성을 울립니다.

## 터치디자이너를 넘어서는 것들

- **공명 (♪)** — 역방향 루프. 일반적인 TD 작품은 자극을 받아 그림을 그리는 데서 끝나지만, 여기서는 그림의 상태(에너지, 움직임)가 다시
  드론 사운드의 필터를 열고, 사용자의 **목소리 음정을 실시간으로 추적해 5도 위와 아래 3도 화음으로 대답**합니다. 각 모드마다 음계가 다릅니다.
  자기 자신의 소리를 다시 듣고 반응하지 않도록 하울링 방지 로직이 들어 있습니다.
- **음정 = 색 (공감각)** — 음이름(pitch class)이 색상환 위의 위치에 대응합니다. 같은 '라' 음은 옥타브와 상관없이 언제나 같은 색입니다.
- **별자리 각인** — 큰 비트가 들어오는 순간 카메라에 잡힌 내 윤곽이 별가루로 피드백 버퍼에 새겨지고, 우주에 휩쓸려 흩어집니다.
- **중력 렌즈 손끝** — 누르는 시간만큼 커지는 블랙홀(사건의 지평선 + 광자 고리)이 생기고, 지나간 빛(피드백)을 휘게 합니다.
  길게 눌렀다 놓으면 화이트홀이 터지고, 화면을 탭하면 별이 음을 냅니다. 두 손가락 핀치는 피드백 시간의 흐름(워프)을 조절합니다.
- **몸의 센서** — 자이로 기울기가 중력의 방향과 3D 시점이 되고(오래 기울인 자세가 천천히 새로운 수평이 됨), 폰을 흔들면 초신성이 터집니다.
  안드로이드에서는 비트에 맞춰 진동이 옵니다.
- **꿈꾸는 모드** — 7초 동안 아무 자극이 없으면 우주가 스스로 가상의 리듬, 스펙트럼, 끌개를 만들어 즉흥연주하며 모드를 순환합니다.
  카메라나 마이크 권한이 없어도 작품이 멈추지 않습니다.
- **색의 강도와 길이** — 빠르고 강한 자극일수록 차가운 보라·청록에서 산호 → 금빛 → 백열로 달아오르고, 자극이 오래 이어질수록(소리, 움직임, 손끝)
  팔레트가 좁은 보라빛에서 무지개 전체로 퍼집니다. 파티클은 태어날 때 청록, 나이 들수록 마젠타·호박색으로 변하고(별의 일생), 비트와 탭은 색을 한 칸씩 밀어냅니다.
- **서울의 하늘** — 한국 시간 기준 실제 태양 고도를 계산해 배경이 밤 → 새벽 여명 → 일출 → 낮 → 일몰 → 황혼으로 바뀝니다.
  노을 시간에는 파티클과 정령도 따뜻해집니다. `?time=17:20` 처럼 주소 뒤에 붙이면 다른 시간을 미리 볼 수 있어요.
- **눈을 가진 정령들** — 흐름을 타고 떠다니는 작은 빛의 정령들이 각자의 리듬으로 깜빡이고, 움직이는 방향이나 손끝을 바라보며,
  큰 소리가 나면 눈이 커지고 입을 벌립니다.
- **기록과 공유** — `●` 버튼은 화면과 공명 사운드를 함께 영상(mp4/webm)으로 녹화하고, `◻` 버튼은 스냅샷을 찍습니다. 모바일에서는 공유 시트가 열립니다.
- **적응형 품질** — 프레임이 떨어지면 해상도를 자동으로 낮춰 저사양 폰에서도 부드럽게 돌아갑니다.

카메라와 마이크 데이터는 모두 기기 안의 GPU와 Web Audio에서만 처리되고, 어디에도 전송되지 않습니다.

## 파일 구조

```
index.html        시작 화면, UI
style.css
src/main.js       렌더 루프, 오퍼레이터 체인, HUD, 녹화
src/shaders.js    모든 GLSL 오퍼레이터
src/audio.js      오디오 분석(밴드, 비트, 피치)과 공명 신시사이저
src/input.js      멀티터치, 자이로, 흔들기
src/gl.js         WebGL2 헬퍼
```
