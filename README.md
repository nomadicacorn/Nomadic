# 🐦 파랑새 쪽지 (Nomadic)

친구들이 각자 **윈도우 PC**에서 쓰는 소식 전하기 앱이에요.
친구가 쪽지를 보내면 **파랑새가 편지를 물고 내 화면 위로 날아와서** 오른쪽 아래에 앉아 기다려요.
새를 누르면 편지가 펼쳐지고, 답장하거나 "고마워 파랑새야 💙"를 누르면 새가 다시 날아가요.

![파랑새](app/assets/bird-2.png)

## 어떻게 동작하나요?

```
 [민지 PC] 파랑새 쪽지 앱 ─┐
 [준호 PC] 파랑새 쪽지 앱 ─┼──  🏤 우체국 서버 (server/)
 [서연 PC] 파랑새 쪽지 앱 ─┘     같은 "둥지 코드"끼리만 쪽지 전달
```

- `app/` — 윈도우 앱 (Electron). 트레이에 상주하고, 투명한 창 위로 파랑새 PNG가 날아다녀요. 새/편지가 없는 곳은 클릭이 그대로 통과해서 작업을 방해하지 않아요.
- `server/` — 쪽지를 중계하는 아주 작은 우체국 서버 (Node.js + WebSocket). 꺼져 있던 친구에게는 다음에 켰을 때 배달해요.
- `tools/make_bird.py` — 파랑새 PNG 그림을 만드는 스크립트 (그림을 바꾸고 싶으면 `app/assets/` 의 PNG를 직접 교체해도 돼요).

## 기능

- 💌 모두에게 / 특정 친구에게 쪽지 보내기 (편지지 색 4가지)
- 🐦 받을 때: 파랑새가 날아와서 짹짹 → 클릭하면 편지가 펼쳐짐
- 🕊️ 보낼 때: 내 화면에서도 파랑새가 편지를 물고 출발
- 🟢 친구 접속 상태 표시, 오프라인 친구에게도 나중에 배달
- 📬 받은 쪽지함 / 보낸 쪽지함, "다시 배달"로 새를 한 번 더 부르기
- 🔁 윈도우 시작 시 자동 실행, 트레이 아이콘

## 1. 우체국(서버) 열기 — 한 명만 하면 돼요

Node.js 18 이상이 필요해요.

```bash
cd server
npm install
npm start          # 기본 포트 8787
```

친구들이 접속하려면 셋 중 하나를 고르세요.

| 방법 | 우체국 주소 예시 | 비고 |
|---|---|---|
| 같은 와이파이/공유기 | `ws://192.168.0.10:8787` | 서버 PC의 내부 IP (`ipconfig`로 확인). 윈도우 방화벽에서 8787 허용 |
| 무료 클라우드 (Render, Railway, Fly.io 등) | `wss://내앱이름.onrender.com` | `server` 폴더를 배포, 시작 명령 `npm start`. 항상 켜져 있어서 제일 편해요 |
| 집 PC + 포트포워딩 / Tailscale / ngrok | `ws://공인IP:8787` 등 | 공유기 설정 필요 |

> 무료 클라우드는 재시작될 때 저장된 쪽지(`data.json`)가 지워질 수 있어요. 이미 받은 쪽지는 각자 PC에 저장되니 괜찮아요.

## 2. 앱 설치하기 (각자 PC)

### 방법 A — 설치 파일 받기 (추천)
GitHub 저장소의 **Actions → Build Windows app → Run workflow** 를 누르면 몇 분 뒤 `BluebirdNotes-windows` 아티팩트에
설치 파일(`...-nsis.exe`)과 설치 없이 쓰는 파일(`...-portable.exe`)이 생겨요. 친구들에게 나눠 주세요.

> 서명되지 않은 앱이라 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누르세요.

### 방법 B — 직접 빌드
```bash
cd app
npm install
npm start          # 바로 실행해 보기
npm run dist       # app/dist 에 윈도우 설치 파일 생성 (윈도우에서 실행 권장)
```

## 3. 처음 설정

앱을 처음 켜면 설정 화면이 나와요.

1. **내 이름** — 친구들에게 보일 이름
2. **둥지 코드** — 친구들과 똑같이 맞추는 비밀 코드 (예: `우리반-파랑새-2026`). 같은 코드끼리만 쪽지가 오가요
3. **우체국 주소** — 서버를 연 친구에게 받은 주소

저장하면 오른쪽 위에 **● 연결됨** 이 뜨고, 쪽지를 주고받을 수 있어요.
창을 닫아도 트레이(시계 옆)에 남아서 쪽지를 기다려요. 완전히 끄려면 트레이 아이콘 우클릭 → 종료.

## 한 PC에서 여러 명 테스트하기

```bash
# 터미널 1
cd server && npm start
# 터미널 2, 3 (PowerShell이면 $env:BLUEBIRD_PROFILE="C:\\temp\\a")
cd app && BLUEBIRD_PROFILE=/tmp/a npm start
cd app && BLUEBIRD_PROFILE=/tmp/b npm start
```

## 알아 둘 점

- 둥지 코드가 곧 비밀번호예요. 쪽지는 서버를 연 사람이 볼 수 있으니 민감한 내용은 피해 주세요.
- 인터넷 주소로 열 때는 `wss://`(HTTPS 지원 호스팅)를 쓰는 걸 권장해요.
